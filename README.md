## Repository Naming Convention

Format:

COHORT-MAIN-TEAMID-PRODUCTNAME

Examples:

- `2023-27-MAIN-A1-AegisSys`
- `2023-27-MAIN-A2-TrustLens`
- `2023-27-MAIN-B1-ProductName`

The letter identifies the batch, and the number identifies the team within that batch.

## Project Requirements

Each team repository should include:

- Project title and abstract
- Team members and project guide
- Problem statement and objectives
- Technologies used
- Installation and execution instructions
- Screenshots or demo link
- Project report and presentation, where required

## Submission and Evaluation

1. Students maintain their working repositories.
2. An official repository is maintained in the VAST-CSE organization for each team.
3. The project guide reviews the source code and documentation.
4. The project coordinator adds the repository link to this directory.
5. Approved projects may be published for juniors to explore.

## Publication Policy

Keep projects private during evaluation unless publication is approved by the department.

Before making a project public, check for API keys, passwords, personal data, confidential information, and third-party licensing restrictions.
